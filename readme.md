# VITYL: Bio-Neural Rescue Mesh 🛰️ ❤️

**Built for the Google Solution Challenge 2026**

## 💡 The Problem
In disasters (floods, earthquakes), phone towers fall. Survivors become invisible. VITYL solves this by creating a "Ghost-Net"—a phone-to-phone network that works without the internet.

## 🛠️ How it Works (The Tech)
* **Gemini Nano:** Detects emergency sounds/impacts directly on the phone.
* **Google Nearby API:** Connects phones via Bluetooth to pass SOS messages like a bucket brigade.
* **Google Maps:** Shows rescuers exactly where the help signals are coming from.

## 🚀 Vision
To ensure that in any crisis, silence isn't a death sentence.
